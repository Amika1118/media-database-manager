What it does

Built for a growing collection

Multi-type management

Movies, TV series and anime each get their own database, so a season count or airing status never gets mixed in with a runtime.

Search, five ways

Look up a title by name, year, or genre - or run a super search that combines genre, country, year and rating at once.

Rating and metadata

Every entry carries a 1–5 star rating, one or more genres from 20 categories, and a country of origin from 13 and counting.

Plain CSV storage

No server, no database engine - entries live in editable CSV files that are created automatically on first run.

Get it running

Two commands and Python

# clone and run - no external dependencies
git clone https://github.com/yourusername/media-database-manager.git
cd media-database-manager
python Movie_record.py
